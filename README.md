# html-govindproj

## Productivity Dashboard (AHT Tracker)
- Open `dashboard.html` in a browser.
- Click "Upload CSV" and select your AHT file.
- Required headers: `Process`, `Allocated`, `Processed`, `Productivity%`, `Average AHT`.
- You can download `aht_template.csv` to start.

Metrics:
- Overall Productivity = Total Processed / Total Allocated × 100
- Overall Avg AHT = Weighted average by Processed count
